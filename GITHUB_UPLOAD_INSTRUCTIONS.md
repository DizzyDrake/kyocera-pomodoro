# Add the README and tomato image to your existing GitHub repository

This ZIP is a documentation-only companion to the November 22 tomato-icon overlay for **Dura Pomodoro v0.2.1**. It does not alter app source code, the Android manifest, timer behavior, version numbers, or signing.

1. Open the existing GitHub repository (the one containing `app/` and `.github/`).
2. Extract this archive and upload **README.md** and **repo-assets/dura-pomodoro-tomato-icon.png** to the repository root, preserving `repo-assets/` as a folder. Replace the old root README only after reviewing any changes you made to it.
3. In the repository sidebar, choose the **About** gear/edit icon and paste the contents of `GITHUB_ABOUT_350_CHARACTERS.txt` into **Description**. The About file itself does not need to be committed.
4. Commit the changes. GitHub should now render the tomato graphic beneath the title in the README.

If you have not yet applied the app launcher icon, use the separately prepared `DuraPomodoro_v0.2.1_TOMATO_ICON_GITHUB_OVERLAY_20261122.zip` from the earlier icon package as well. That separate package contains the manifest and Android launcher assets.

The README describes the saved v0.2.1 source. If your repository remains at v0.1.11, do not use the v0.2.1 feature descriptions until its source has been updated.
