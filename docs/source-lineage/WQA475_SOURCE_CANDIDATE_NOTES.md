# WQA475 source-only candidate
Derived from WQA473; original preserved. Shares idempotent legacy active-deadline migration between ordinary Activity launch and boot. Commit must succeed before canceling legacy alarm; on successful migration reschedules generation-specific token or invokes expired completion. No Android compile, device tests, or runtime PendingIntent tests. Remaining: cross-component transaction serialization, cancel-before-commit, notification durability, migration atomicity with concurrent receiver, and overflow of legacy generationCounter (preserved, not cleared). Do not deploy as release.
